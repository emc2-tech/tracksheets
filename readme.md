# TrackSheets

A modern spreadsheet application built with React and Python Flask, combining the familiarity of Excel with modern web technologies.

## Features

- 📊 Excel-style interface with green sidebar navigation
- 🎨 Multiple pre-built templates (Budget, Sales Report, Customer Database, etc.)
- 🔄 Real-time workbook creation and management
- 📁 Automatic file organization and metadata tracking
- 🌐 RESTful API backend with Flask
- ⚡ Fast React frontend with Vite
